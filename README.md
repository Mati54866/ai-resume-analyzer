## <a name="introduction">✨ Introduction</a>

An AI-powered Resume Analyzer built with React, React Router, and Puter.js. Upload resumes, match candidates to jobs using AI evaluations, and get custom feedback with ATS scores tailored to each job listing.

## <a name="tech-stack">⚙️ Tech Stack</a>

- **[React](https://react.dev/)** - UI library with reusable components
- **[React Router v7](https://reactrouter.com/)** - Routing and navigation
- **[Puter.js](https://jsm.dev/resumind-puterjs)** - Serverless auth, storage, and AI integration
- **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first styling
- **[TypeScript](https://www.typescriptlang.org/)** - Type-safe JavaScript
- **[Vite](https://vite.dev/)** - Build tool and dev server
- **[Zustand](https://github.com/pmndrs/zustand)** - State management

## <a name="features">🔋 Features</a>

👉 **Easy Authentication**: Handle authentication entirely in the browser using Puter.js—no backend required.

👉 **Resume Upload & Storage**: Upload and store all resumes in one safe, reliable place.

👉 **AI Resume Matching**: Get ATS scores with custom feedback tailored to each job listing.

👉 **Reusable UI Components**: Clean, consistent components for a maintainable interface.

👉 **Cross-Device Compatibility**: Fully responsive design for all devices.

👉 **Modern UI/UX**: Clean design with Tailwind CSS for a sleek user experience.
